# NoteNest — Notes Application

NoteNest is a responsive notes application built with HTML, CSS, and JavaScript. It helps users create, edit, search, pin, and delete notes with automatic browser-based storage.

## Features

- Create and edit notes
- Search notes by title or content
- Pin important notes
- Delete notes with confirmation
- Automatically save notes using Local Storage
- Responsive interface
- Keyboard shortcuts for search and creating notes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.

For the best development experience, use the VS Code Live Server extension.

## Data Storage

Notes are stored in your browser's Local Storage. They are not automatically synchronized between devices or browsers.
